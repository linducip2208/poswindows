# كاسير برو — نظام نقاط بيع تجزئة احترافي يعمل دون اتصال لنظام ويندوز

**🌐 اللغة / Language / Bahasa:**
[🇮🇩 إندونيسيا (README.md)](README.md) · [🇬🇧 الإنجليزية (README.EN.md)](README.EN.md) · [🇸🇦 العربية (README.AR.md)](README.AR.md)

---

تطبيق نقاط بيع (POS) لسطح المكتب ويندوز يعمل **بنسبة 100% دون اتصال بالإنترنت**، مخصص
لمتاجر التجزئة: مبني بلغة C# وواجهة WinForms مع قاعدة بيانات SQLite محلية وإطار .NET 10 —
بدون إنترنت، بدون خادم، بدون سحابة. التطبيق **محمول بالكامل**: جميع البيانات داخل مجلد
التطبيق، ويمكن نقله إلى أي وسيط تخزين (فلاشة، قرص خارجي، قرص D أو E).

**مصمم لـ:** المنافل الصغيرة، محلات البقالة، محلات الملابس، المحلات الشاملة، محلات قطع
الغيار، محلات الإلكترونيات، مستحضرات التجميل، الأغذية المجمدة، محلات مواد البناء الصغيرة
والمتوسطة، وجميع أنواع التجزئة العامة.

**الخصائص الأساسية:** تطبيق ويندوز أصلي · مسح باركود فائق السرعة · ملائم للوحة المفاتيح
وشاشات اللمس · متوافق مع أجهزة نقاط البيع · نسخ احتياطي سهل · قاعدة بيانات آمنة من التلف.

## ✨ قائمة الميزات الكاملة (الإصدار 2.0.0)

### 🛒 شاشة الكاشير (نقاط البيع)
- **مسح الباركود الفوري** — ذاكرة تخزين مؤقت في الذاكرة (يتم تحميل جميع الباركودات وأرقام
  SKU مرة واحدة)، صفر استعلامات قاعدة بيانات عند كل مسح، مع الرجوع إلى قاعدة البيانات
  تلقائياً في حالة عدم وجود الباركود في الذاكرة المؤقتة
- **الدفع المقسّم** — نقدي / QRIS / بطاقة مدين / تحويل / ذمة (آجل) / نقاط ولاء / رصيد متجر،
  بعدد أسطر دفع غير محدود
- **ضريبة القيمة المضافة (PPN)** — شاملة أو مضافة، نسبة قابلة للتعديل، وتجاوز الضريبة لكل
  منتج (بدون ضريبة / شاملة / مضافة)
- **تعليق / إيقاف المعاملة** — إيقاف عدة سلات لكل كاشير مع الاستدعاء حسب الاسم أو العميل
- **العروض الترويجية** — خصم بالنسبة المئوية، خصم ثابت، اشترِ X واحصل على Y (الأرخص مجاناً)،
  سعر خاص، نوافذ زمنية (ساعات سعيدة)، جدولة أيام الأسبوع، عروض للأعضاء فقط، حد أدنى
  للمبلغ/الكمية، سياسة التكديس أو أفضل عرض فقط
- **كوبونات / قسائم** — أكواد غير متصلة بالإنترنت (مثل PROMO10)، حد إجمالي للاستخدام، حد
  لكل عميل
- **أسعار متعددة المستويات** — تجزئة / عضو / جملة 1-3 / موزع إعادة بيع / موزع، مع شرائح
  الكمية؛ ترتيب الحل الحتمي: العرض الترويجي ← مستوى سعر العميل ← شريحة الكمية ← السعر
  الأساسي
- **سعر الجملة لكل منتج** مع حد أدنى للكمية (يُعاد تقييمه تلقائياً مع تغيّر الكمية)
- **دعم باركود الميزان** — باركود EAN-13 بوزن مدمج (بادئة + رمز المنتج + الوزن)، بادئات
  وقاسم وزن قابلين للتعديل
- **نافذة نجاح الدفع** — ملخص كبير: الإجمالي / المدفوع / المتبقي مع زري طباعة الإيصال /
  عملية جديدة
- **التعامل مع فشل الطابعة** — تُحفظ العملية دائماً حتى لو فشلت الطباعة (إعادة المحاولة /
  تخطي)
- **فتح درج النقد** — نبضة ESC/POS عبر خدمة الطباعة في ويندوز، محمية بالصلاحيات
- **اختصارات لوحة المفاتيح** — F2 للباركود، F5 للتحديث، F9 للدفع، F11 لملء الشاشة، ESC
  للإلغاء؛ وضع اللمس بعناصر أكبر؛ تسجيل خروج تلقائي عند الخمول

### 🔐 الأمان (التحكم بالصلاحيات RBAC)
- **4 أدوار** — المالك / المدير / المشرف / الكاشير مع **أكثر من 35 صلاحية دقيقة**
  (POS.USE، SALE.VOID، PRODUCT.DELETE، USER.MANAGE، BACKUP.RESTORE، DRAWER.OPEN…)
- تُفرض الصلاحيات **في طبقة الخدمات** — إخفاء القوائم مجرد واجهة؛ استدعاء أي دالة مقيّدة
  مباشرة سيفشل وسيُسجَّل في سجل التدقيق
- **نافذة تفويض المشرف** — الإجراءات الحساسة (إلغاء عملية، تعديل المخزون، فتح الدرج يدوياً،
  استعادة قاعدة البيانات، الخصومات الكبيرة) تتطلب رمز مشرف/مدير؛ يُحفظ كل موافقة في جدول
  `approval_log` مع مَن طلب ومَن وافق والسبب والوقت
- **قفل تسجيل الدخول** — 5 محاولات فاشلة = قفل لمدة دقيقة؛ كلمات المرور محفوظة بتشفير
  PBKDF2-SHA256 مع مقارنة زمن ثابت؛ لا نص صريح إطلاقاً
- **تقارير Z غير قابلة للتعديل**؛ سجل تدقيق كامل (دخول، بيع، إلغاء، مرتجع، استبدال، تجاوز
  خصم، درج، نقد داخل/خارج، تعديلات مخزون، تحويلات، مشتريات، مدفوعات موردين، تغييرات
  المستخدمين، الإعدادات، النسخ الاحتياطي، الاستعادة، الترخيص)

### 📦 المخزون
- **دفتر حركات المخزون** — كل تغيير في المخزون يُنشئ سجلاً في `stock_movements` (المنتج،
  الاتجاه، الكمية، قبل/بعد، المرجع، المستخدم، الوقت)؛ مخزون المنتج يساوي دائماً مجموع
  الدفتر
- **مستودعات متعددة** — المتجر الرئيسي والمستودعات، جدول مخزون لكل مستودع
- **تحويل مخزون** بين المستودعات (ذرّي ومسجّل في الدفتر)
- **الجرد الفعلي** بسير عمل: مسودة ← جرد ← مراجعة ← ترحيل
- **تتبع الدفعات / التواريخ** — استهلاك FEFO (الأقرب انتهاءً أولاً)، تقرير قرب الانتهاء بحد
  قابل للتعديل (7/14/30/60/90 يوماً)، شطب المخزون المنتهي
- **سجل الأرقام التسلسلية / IMEI** — دورة حياة متاح/مباع/مرتجع/تالف، مع منع التكرار
- **نظام إعادة الطلب** — نقطة إعادة الطلب، المخزون المستهدف، متوسط المبيعات اليومية، مدة
  التوريد؛ الكمية المقترحة = الأكبر من (المستهدف − المتاح) أو (المتوسط اليومي × مدة التوريد)
- **متوسط التكلفة المتحرك** بالسنتات الصحيحة، يُعاد حسابه عند كل عملية شراء
- **تحليلات البضائع سريعة/بطيئة/الراكدة** الحركة (نافذة بدون بيع قابلة للتعديل)
- **تقييم المخزون** (الكمية × متوسط التكلفة)

### 🛬 المشتريات
- **الوضع البسيط** — شراء مباشر مع إدخال المخزون تلقائياً (الافتراضي)
- **سير عمل متقدم** — أمر شراء ← استلام بضاعة (استلام جزئي) ← فاتورة مورد ← دفع (مسودة/
  مطلوب/مستلم/مغلق/ملغى)
- **مستحقات الموردين** — تتبع المشتريات الآجلة، دفعات جزئية، الدفعات النقدية تظهر في تقرير
  نقدية الوردية
- **مرتجع المشتريات** — جزئي، ولا يتجاوز الكمية المستلمة

### 👥 العملاء والولاء
- بيانات العميل: الرمز، الاسم، الهاتف، البريد، العنوان، تاريخ الميلاد، الفئة
  (عادي/فضي/ذهبي/بلاتيني)، مستوى السعر، ملاحظات
- **دفتر نقاط الولاء** — كسب / استبدال / تعديل / انتهاء / عكس؛ معدل كسب وقيمة استبدال
  قابلان للتعديل؛ يمكن استخدام النقاط كوسيلة دفع
- **دفتر رصيد المتجر** — إضافة (مرتجع بدون استرداد نقدي) / خصم (استخدام في الشراء)، بسجل
  كامل وليس مجرد إجمالي
- **الذمم المدينة (آجل)** — حد ائتمان لكل عميل، تواريخ استحقاق، تسويات جزئية، ولا يمكن
  إلغاء عملية عليها ذمة قائمة قبل التسوية

### 📊 التقارير والتصدير
- أكثر من 12 تقريراً مباشراً من SQLite: المبيعات، المشتريات، الأرباح، مبيعات المنتجات،
  المخزون، حركات المخزون، النواقص، النقدية، الكاشير، المبيعات بالساعة، حسب وسيلة الدفع،
  حسب الفئة
- **تقرير X** (الوردية الجارية) و**تقرير Z** (الإغلاق النهائي غير القابل للتعديل) مع تفصيل
  طرق الدفع، النقد المتوقع/الفعلي/الفرق، تسويات الذمم، المرتجعات
- **تصدير PDF** — مُنشئ PDF مدمج بدون أي اعتماديات خارجية (A4 أفقي، ترقيم صفحات، رؤوس)
- تصدير CSV والطباعة عبر طابعات ويندوز (A4/A5)
- تقرير النقدية لكل وردية مع دعم فئات النقود

### 💾 البنية التحتية للعمل دون اتصال
- **SQLite** — وضع WAL، تفعيل المفاتيح الأجنبية، مزامنة NORMAL، مهلة انشغال 10 ثوانٍ،
  إعادة محاولة تلقائية ×3 عند الانشغال، صيانة دورية خفيفة (checkpoint + optimize +
  quick_check)
- **نسخ احتياطي آمن** — واجهة SQLite Backup API (وليس نسخ ملف خام أثناء التشغيل)، مع
  التحقق integrity_check لكل نسخة، تلقائي عند إغلاق الوردية/الخروج، مدة احتفاظ قابلة
  للتعديل
- **الاستعادة** — التحقق من الملف ← نسخة احتياطية قبل الاستعادة ← استبدال ذرّي ← التحقق من
  القاعدة المستعادة (للمدير فقط، مع تدقيق)
- **التحديث دون اتصال** — حزمة التحديث = manifest.json + الملفات + **توقيع ECDSA**؛ SHA-256
  لكل ملف؛ حماية من اجتياز المسار؛ لا يتم أبداً الكتابة فوق Data/Backup/Logs/license؛
  تُطبَّق عند التشغيل التالي (USB / مشاركة شبكة، بدون إنترنت)
- **الترخيص دون اتصال** — رموز موقعة بـ ECDSA P-256، مرتبطة بالجهاز، تُتحقق عند كل تشغيل؛
  تطبيق Keygen منفصل (المفتاح الخاص محمي بـ DPAPI ولا يُشحن أبداً)
- **واجهة ثنائية اللغة** — الإندونيسية / الإنجليزية (كتالوج نصوص مركزي)

## 🏗 البنية المعمارية

```
KasirPro.App             واجهة WinForms (net10.0-windows)
KasirPro.Core            النطاق: الكيانات، النقود (سنتات صحيحة)، الحاسبات، محرك العروض
KasirPro.Infrastructure  SQLite (Dapper)، الخدمات، الترحيلات، الطباعة، النسخ، التحديث
KasirPro.Licensing       معرف الجهاز + التحقق من رموز ECDSA P-256 (المفتاح العام فقط)
KasirPro.Keygen          مولد المفاتيح الرئيسي (للمطور فقط): مفتاح خاص DPAPI + keygen.db
KasirPro.Tests           157 اختبار آلي xUnit
```

الترتيب: الواجهة ← الخدمات ← النطاق ← البنية التحتية ← SQLite.
**النقود تُخزَّن كسنتات صحيحة** (أبداً أرقام عشرية عائمة). جميع العمليات التجارية ذرّية
(transactional). تُفحص الصلاحيات في الخدمات وليس في الواجهة فقط.

## 🔨 البناء والاختبار

يتطلب .NET 10 SDK:

```
dotnet restore
dotnet build -c Release
dotnet test tests/KasirPro.Tests -c Release
```

أو مباشرة: `powershell scripts\build-release.ps1`

## 📦 النشر

```
# محمول (يتطلب .NET Desktop Runtime 10 على جهاز المستهدف)
powershell scripts\publish-portable.ps1

# شامل ذاتياً (لا يحتاج وقت تشغيل، ~112 ميجابايت)
powershell scripts\publish-selfcontained.ps1
```

الناتج: `dist/KasirPro/KasirPro.exe` + `dist/DeveloperTools/KasirPro.Keygen/`
(المفاتيح الخاصة لا تُشحن أبداً في حزمة العميل).

## ▶ التشغيل

```
KasirPro.exe                          # الواجهة الكاملة
KasirPro.exe --print-machine-id       # معرف جهاز هذا الكمبيوتر
KasirPro.exe --verify-license <tok>   # التفعيل عبر سطر الأوامر
KasirPro.exe --seed-demo              # بيانات تجريبية (تطوير)
KasirPro.exe --reset-demo             # إعادة ضبط قاعدة البيانات للتجربة
KasirPro.exe --diag-license           # بصمة المفتاح العام + حالة الترخيص
```

ترتيب الإقلاع: فحص الترخيص ← التفعيل (إن لزم) ← معالج الإعداد الأول (بيانات المتجر، رمز
المدير، الطابعة) ← تسجيل الدخول ← لوحة المعلومات.

## 🗄 قاعدة البيانات (SQLite)

الملف: `<مجلد التطبيق>\Data\pos.db` (مسار نسبي — انقل المجلد وتنتقل القاعدة).
`foreign_keys=ON`، `journal_mode=WAL`، `synchronous=NORMAL`، مهلة انشغال 10 ثوانٍ، إعادة
محاولة ×3، صيانة دورية خفيفة. ترحيلات مُرقّمة v1–v5 (ذرّية ومتكررة آمنة) — قواعد البيانات
القديمة تترقّى بأمان.

## 💾 النسخ الاحتياطي / الاستعادة

- يدوي: الأدوات ← Backup Database
- تلقائي: عند إغلاق الوردية وعند الخروج مع تغيّر البيانات؛ مدة الاحتفاظ قابلة للتعديل (3–100)
- يستخدم واجهة SQLite Backup API + فحص integrity_check لكل نسخة
- الاستعادة: تحقق ← نسخة احتياطية قبلية ← استبدال ← تحقق (للمدير فقط، مع تدقيق)

## 🖨 الطابعات

- أدوار طابعات منفصلة: إيصالات (58/80 مم)، ملصقات، فواتير A4، تقارير، موصل الدرج
- الطباعة الحرارية عبر PrintDocument في ويندوز؛ طابعات البلوتوث/الشبكة المثبتة في ويندوز
  تظهر تلقائياً (الإعدادات ← الطابعات)
- درج النقد: نبضة ESC p 0 عبر Winspool RAW، تتطلب صلاحية DRAWER.OPEN + تدقيق
- **مركز اختبار الأجهزة**: الأدوات ← Hardware Test Center (الماسح / الطابعات / الدرج / الميزان)

## 📷 قارئ الباركود

- وضع HID (الافتراضي): القارئ يعمل كلوحة مفاتيح، لاحقة Enter، تركيز تلقائي
- وضع COM: اختر المنفذ من مركز اختبار الأجهزة
- الاختبار: امسح في تبويب الماسح ← يظهر القيمة الخام والنوع والمنتج المطابق وSKU والسعر
  والمخزون؛ ورسالة "الباركود غير مسجل" عند عدم المعرفة
- الذاكرة المؤقتة: الباركودات وأرقام SKU تُحمَّل مرة واحدة (مع الرجوع للقاعدة عند الحاجة)

## 🏷 الباركود والملصقات

- الأدوات ← Barcode & Labels: توليد EAN-13 داخلي (رقم تحقق GS1 صحيح)، فاحص التكرار، مدقق
  GTIN، مصمم ملصقات (من 25×15 حتى 50×40 مم)، معاينة + طباعة بالجملة، مُنشئ Code128 مدمج

## 🔑 الترخيص / مولد المفاتيح

نموذج ECDSA P-256. المفتاح الخاص في مولد المفاتيح (محمي بـ DPAPI وكلمة مرور)؛ تطبيق نقاط
البيع يحمل المفتاح العام فقط. صيغة الرمز `KPR1.<payload>.<signature>`، تُتحقق عند كل تشغيل،
مقيدة بالجهاز.

```
KasirPro.Keygen.exe --init <كلمة المرور>
KasirPro.Keygen.exe --generate "اسم المتجر" KP-XXXX-XXXX-XXXX lifetime <كلمة المرور>
KasirPro.Keygen.exe --fingerprint
```

قارن البصمة: يجب أن يطابق `KasirPro.exe --diag-license` بصمة المولد.

## 🔄 التحديث دون اتصال

1. المطور: `UpdateService.BuildPackage(...)` ← manifest.json + الملفات + manifest.sig (ECDSA)
2. انسخ مجلد الحزمة إلى USB/مشاركة، وحدده في إعدادات المتجر
3. الأدوات ← Check for Update (Offline): تحقق التوقيع + SHA-256 لكل ملف + حماية المسار ←
   التجهيز ← التطبيق عند التشغيل التالي
4. لا تُكتب فوق مجلدات Data/ وBackup/ وLogs/ وlicense.dat أبداً

## 👮 الأدوار والصلاحيات

| الدور | يملك | لا يملك |
|-------|------|---------|
| المالك | كل شيء | — |
| المدير | كل شيء | — |
| المشرف | الإلغاء/المرتجع/الاستبدال، تعديل المخزون، الدرج، الموافقات | إدارة المستخدمين، إدارة الأدوار، الاستعادة |
| الكاشير | نقطة البيع، التعليق/الاستدعاء، المرتجعات، الخصومات | الإلغاء، إدارة المستخدمين، الاستعادة، الإعدادات، حذف المنتج |

تُضبط الصلاحيات عبر جدول `role_permissions`. تخفي القائمة ما لا يملكه المستخدم، وترفض
الخدمات الاستدعاء المباشر (مع تسجيل في التدقيق).

## 🧯 استكشاف الأخطاء

- **الطابعة غير موجودة** — ثبّتها في ويندوز أولاً ثم اضغط Refresh
- **طابعة بلوتوث لا تطبع** — قم بالإقران مع ويندوز حتى تظهر في قائمة الطابعات؛ التطبيق لا
  يتصل بالبلوتوث مباشرة
- **القارئ غير مكتشف** — وضع HID يحتاج التركيز في حقل الباركود؛ وضع COM يحتاج المنفذ
  الصحيح؛ جرّبه من مركز اختبار الأجهزة
- **قاعدة البيانات مقفلة** — إعادة المحاولة تلقائية ×3؛ لا تشارك pos.db عبر الشبكة
- **الترخيص غير صالح** — قارن البصمة (`--diag-license` مقابل `--fingerprint`)
- **فشل النسخ الاحتياطي** — تأكد من إمكانية الكتابة في مجلد التطبيق
- **خطأ منفذ COM** — المنفذ مستخدم من برنامج آخر؛ أغلقه ثم حدّث
- **صلاحية الكتابة في ويندوز** — شغّل التطبيق من مجلد قابل للكتابة (ليس Program Files)
